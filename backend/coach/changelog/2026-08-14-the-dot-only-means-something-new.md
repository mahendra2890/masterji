title: The What's new dot no longer nags an account that has never been here
---

The unread dot beside **What's new** was lit for every brand-new browser — so
the first screen after signing up, whose entire job is getting one idea into
one box, carried a marker pointing away from it. What it was offering was this
changelog: entries about changes that shipped before you had an account, none
of which you can have missed. A browser opening Masterji for the first time is
now marked as caught up, and the dot means what it always claimed to — that
something has shipped since the last time you looked.
