title: Hinglish is now switchable before you commit a goal

Masterji has always spoken Hinglish in the workshop — the room before the goal
reads the same language setting every other screen does. The switch that sets
it only existed after you had committed a goal, so the first conversation you
ever had with him was the one conversation you could not put into Hinglish. The
EN / हिं switch is now on that screen too, in the row along the bottom. It
changes nothing about the gate, the same as it never has.
