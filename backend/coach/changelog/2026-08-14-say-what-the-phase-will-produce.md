title: Say what a phase will produce, on the day it opens
---

Every phase told you the same thing it tells everybody — "smallest thing a real
user can touch this week" — and nothing ever learned which thing you decided
that was. When a phase unlocks you can now leave one line under it: what this
phase will have produced. Masterji reads it from then on, so he can tell work
that is going where you said from work that has drifted, and the morning's
reading of your task gets it as context too. It is a note, not a promise: it
changes no count, the gate has never read it and does not start, you can reword
it while the phase is open, and skipping it entirely leaves everything working
exactly as before. The next phase gets its own line, and this one stays where
you left it.
